# NAWARUCO — Demo icon 3D

Tạo bằng imagegen tích hợp, màu chủ đạo xanh nước và xanh lá, bề mặt mờ.

- Ba file *-original.png: ảnh gốc nền trong suốt.
- Bản dùng web 384 × 384: ../../mockup/images/support-icons-3d/.
- Xem thử: ../../mockup/icon-3d-demo.html (hiển thị 112px).
- Prompt đầy đủ và đường dẫn nguồn: manifest.json.
- Đây là PNG raster, không phải SVG hay mô hình 3D có thể sửa khối.
- Bộ linear và trang chủ giữ nguyên.
